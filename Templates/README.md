# Templates

A project folder put here is offered as a starting point in the editor's New Project window.

The engine comes with none: a new project starts empty. The example game (Driving) is
a separate download, `MoltenProjects.zip`: unzip it wherever you keep your projects and open
it with **Open a Project...**, or copy its folder here to start new projects from it.

They are written by `Tools/make_templates.py` (into `../MoltenProjects`, or the folder given
as its argument) and played by the unit tests when that folder is found.
